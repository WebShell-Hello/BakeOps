Recovery model
- compose.yaml, backend/Dockerfile, frontend/Dockerfile and dependency lock files are the source of truth.
- Local backend and frontend images are rebuilt with: docker compose build
- Services are recreated with: docker compose up -d
- The demo database is restored after PostgreSQL is healthy with:
  docker compose exec -T postgres psql -U bakeops -d bakeops < backups/demo/bakeops-demo.sql

Container image tar archives are intentionally not committed. They are large, architecture-specific build artifacts and can be reproduced from the versioned Dockerfiles.
